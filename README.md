## What things cost

Most of these guides use free tools (Python, ffmpeg, Kokoro voice). When a step needs a paid plan, the guide says so at the top.

## A note on honesty

Everything here is something I actually built and use. No income claims, no "get rich" promises. If a step doesn't work for you, it's not you: tools change. Check the date at the top of each guide.
